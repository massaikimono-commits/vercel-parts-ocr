# Stage A21 automatic target selection

Evaluation-only Stage A21 flow. The user selects the formal yellow 12 images once. The browser normalizes filenames, verifies unique 0675-0686 formal coverage, auto-resolves base id 0684, and runs targeted diagnostics only on that image. If mapping is incomplete or ambiguous, the diagnostic stops without asking the user to identify a filename manually.

No Production OCR parameters, Frozen branch, main, Supabase, Netlify Production, Vercel Production, Stage B, or Guided Live are changed.
