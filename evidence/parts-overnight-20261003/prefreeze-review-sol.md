# Prefreeze independent code review

2026-10-04. Inspected `scripts/lib/parts-ocr-overnight-runtime.mjs`, `scripts/parts-ocr-vision-boundary.swift`, `scripts/parts-ocr-overnight-run.mjs`, and the three new architecture modules. No real photographs, GT scalars, or diagnostic scores were opened. Existing orientation, graph, and geometry synthetic tests pass.

## Required before freeze

1. **Yellow paper is excluded by the geometry polarity probe.** `row-first-geometry.mjs:13-16` includes a border pixel only when RGB spread is below 55. A generated `#fff4b0` ruled table has spread 79; the detector returns `background-polarity-unavailable`. The identical black ruled grid on white returns one table. Base background luminance/polarity on all opaque border pixels, while keeping the low-chroma constraint only where useful for ink segmentation. Add a yellow-background geometry regression.
2. **Vision's spaced combined header cannot be split.** `parts-ocr-vision-boundary.swift:36-52` emits character boxes for `\\S+` spans, so spaces have no character boxes. `token-spatial-graph.mjs:23` demands their concatenation equal the whole raw phrase. A synthetic `品名 出庫数 標準価格 単価` line with genuine character boxes therefore produces `no-proven-header-band`. Align provider character boxes while skipping unboxed whitespace, or supply genuine provider range boxes for each candidate header phrase. Add spaced/split header tests.
3. **Ambiguous hypotheses choose the first result.** `parts-ocr-overnight-runtime.mjs:103` makes `hypotheses[0].rows` the output of a cardinal variant even when orientation is tied. Line 111 does the same for multiple rectangle hypotheses. Keep alternative rows in `hypotheses` but leave top-level rows empty on ambiguity, or implement a preregistered document-internal disambiguation rule. The same issue applies to `R_V_CARDINAL` at line 113.
4. **Coordinate provenance is incomplete.** `inverseCardinalBox` is imported but unused. Graph regions are in the rotated, scaled acquisition frame; row-first regions are in the 1200-pixel geometry frame. Carry frame dimensions and forward/inverse transforms with every region or map boxes into source coordinates before output. Test 90/180/270 and downscaling with synthetic labeled rectangles.
5. **Nonempty but rejected numeric OCR is labeled observed.** `parts-ocr-overnight-runtime.mjs:93` sets `status:'observed'` whenever `raw` is nonempty, even if `normalizedNumber(raw)` returns `''`. Preserve raw text and mark `unreadable` or `invalid-numeric` for review; use field-specific quantity/price validation.
6. **The 96-cell cap is applied after all crops are written.** Lines 82-92 save every cell PNG, then slice jobs to 96. Apply the cap before crop creation/writes and mark skipped geometry slots `budget-exhausted`. A 96-job Swift batch returns only at completion; check its duration on synthetic sheets and use small batches with preserved partial results if it approaches the 240-second native timeout.
7. **Cost-column absence is overclaimed.** `token-spatial-graph.mjs:72` sets `absentCostProven` from missing recognized header text and an apparent unit-only schema. A missed header or extra unlabeled numeric column can mimic that evidence. Require a supported white layout with no conflicting physical/graph column, or change the status to `cost-column-not-observed`. The external value may remain `''`, but the internal reason must not claim physical absence without evidence.

## Boundary and readiness notes

- The documented orientation scoring rule has changed from the prior architecture plan. Update that plan to the actual `confidenceMass / sqrt(knownCount) × lineCoherence` formula and fixed 0.9 tie rule before freezing; do not tune them from diagnostic photographs.
- Row-first currently has strict complete-rule topology and can safely abstain on broken/skewed tables. The fallback reported by geometry is descriptive; the runtime does not run full-page graph as a substitute inside the R variant. Keep that variant identity explicit.
- Apple Vision range boxes are provider-derived, with line confidence copied to phrase tokens. Keep `granularity:'phrase'` and confidence provenance in acquisition records; do not interpret copied confidence as independent word certainty.
- The outer runner's 600-second child timeout can discard all seven variant results because the child writes its result only after the matrix finishes. Per-variant checkpoint files or one child per variant would preserve completed work. This is especially relevant with four thumbnail orientations per engine and two cell-OCR variants.
